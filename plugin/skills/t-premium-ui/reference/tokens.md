# Токены T-Premium UI

Все цвета — CSS-переменные из `ds/css/tokens.css`, свои для каждого из четырёх наборов
(`<html data-style="warm|classic" data-mode="light|dark">`). В Tailwind часть из них доступна через preset:
`bg-page`, `border-line`, `text-fg` / `text-fg-muted` / `text-fg-faint`, `text-accent` / `bg-accent-soft` /
`text-accent-text`, `text-pos` / `bg-pos-bg`, `text-neg` / `bg-neg-bg`, `text-warn` / `bg-warn-bg`.

| Токен | Назначение |
|-------|-----------|
| `--page` | фон страницы |
| `--side` | фон боковой панели |
| `--line` | разделители, линии таблиц |
| `--text` | основной текст |
| `--muted` | второстепенный текст, подписи |
| `--faint` | плейсхолдеры, самый слабый текст |
| `--nav-on` | активный пункт навигации, фон аватара |
| `--seg` | фон сегментов и иконочных кнопок |
| `--seg-text` | текст сегментов |
| `--seg-on` | выбранный сегмент |
| `--seg-on-text` | текст выбранного сегмента |
| `--raised` | нажатая кнопка внутри сегмента (поповер оформления) |
| `--raised-shadow` | её тень |
| `--focus` | кольцо фокуса |
| `--accent` | акцент: иконки, звёздочка обязательного поля |
| `--accent-soft` | мягкий акцентный фон (бейдж «идёт», инфо-баннер, выделение текста) |
| `--accent-text` | текст на мягком акцентном фоне, ссылки |
| `--card` | фон карточки формы (градиент в T-Premium светлой) |
| `--card-solid` | сплошной цвет карточки (плитки статистики) |
| `--card-end` | конечный цвет градиента карточки (для проверки контраста) |
| `--card-line` | рамка карточки |
| `--panel` | фон панели |
| `--panel-line` | рамка панели, поповера, диалога |
| `--field` | фон поля ввода |
| `--field-line` | рамка поля ввода, чипа |
| `--chip` | фон чипа с переключателем |
| `--tg-off` | переключатель выключен |
| `--tg-on` | переключатель включён |
| `--knob` | ручка переключателя |
| `--cta` | главная кнопка (может быть градиентом) |
| `--cta-solid` | сплошной цвет главной кнопки (для контраста) |
| `--on-cta` | текст на главной кнопке |
| `--sec` | вторичная кнопка |
| `--sec-line` | рамка вторичной кнопки |
| `--danger` | опасное действие |
| `--on-danger` | текст на опасной кнопке |
| `--log` | фон блока лога |
| `--log-text` | текст лога |
| `--log-muted` | время и служебное в логе |
| `--log-line` | разделители и кнопки лога |
| `--log-warn` | строки WARNING |
| `--log-err` | строки ERROR |
| `--row-alt` | чередующиеся строки, подсветка строки таблицы |
| `--pos-bg` | фон «успех» |
| `--pos-text` | текст «успех» |
| `--neg-bg` | фон «ошибка» |
| `--neg-text` | текст «ошибка», рамка поля с ошибкой |
| `--warn-bg` | фон «предупреждение» |
| `--warn-text` | текст «предупреждение» |
| `--mark-a` | логотип: начало градиента плитки |
| `--mark-b` | логотип: конец градиента плитки |
| `--mark-ink` | логотип: цвет знака |
| `--scrim` | затемнение под диалогом |
| `--pop` | фон поповера, диалога, карточки входа |
| `--pop-shadow` | их тень |
| `--auth-bg` | фон страницы входа |
| `--swatch-warm` | кружок стиля T-Premium в поповере |
| `--swatch-classic` | кружок стиля Классика в поповере |
