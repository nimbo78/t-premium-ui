# T-Premium UI

Дизайн-система внутренних инструментов (вид Switch Sync): CSS-ядро, шрифты, светлая / тёмная / авто-тема,
React-компоненты и скилл Claude Code, который подключает систему в проект и обновляет её.

Установка: `/plugin marketplace add nimbo78/t-premium-ui`, затем `/plugin install t-premium-ui@t-premium-ui`.
В проекте: «подключи дизайн-систему», позже — «обнови дизайн-систему».

Шрифты T-Sans и Neue Haas Unica лицензированы Т-Банку: система используется только внутри банка,
репозиторий приватный.
